Designing the game.

- [`INSIDE_GAME_DESIGN.md`](INSIDE_GAME_DESIGN.md): what a player experiences while playing a match against
  others, as the game plays now: the levels and how they look, movement, controls, weapons, and how a round and a
  match are won, each level and weapon described by the same parameters.
- [`OUTSIDE_GAME_DESIGN.md`](OUTSIDE_GAME_DESIGN.md): whatever manages how and when matches are played: accounts,
  paying, the kinds of game, starting games, matchmaking, rating, fair play and friends. Most of it is designed
  but not built yet.
- [`WINDOW_DESIGN.md`](WINDOW_DESIGN.md): how the app's windows work: which windows there are, how a player gets
  from one to the next, what each shows, which settings it has and who may change them.
- `inside_game_design/`, `outside_game_design/` and `window_design/`: the pictures that belong to each of the three
  design docs above (diagrams, mock-ups, screenshots), one folder per doc. A folder is made with its first picture.
  [`window_design/`](window_design/README.md) points to the mock-up of the windows to come, a website to click
  through.
- [`cloud/`](cloud/README.md): the system design of the online side (services, databases, APIs, protocols). Not
  written yet; its README points to the prototype that simulates it.
- [`FOUR_MAPS_HANDOFF.md`](FOUR_MAPS_HANDOFF.md): the state of the four level demos and the match on 2026-11-08, for
  whoever continues that work.
- [`slides/`](slides/README.md): the official slide deck of the game as it is now, with pictures of the game.
- [`slides_preliminary/`](slides_preliminary/README.md): the preliminary design deck, from before the game was built,
  kept for history.
- [`brainstorm/`](brainstorm/): raw notes that `INSIDE_GAME_DESIGN.md` is based on.
