Designing the gameplay.

- [`DESIGN.md`](DESIGN.md): the current game design: match rules, levels and weapons, each level
  and weapon described by the same parameters.
- [`GLOSSARY.md`](GLOSSARY.md): the words of the game, one meaning each. Every agent uses them.
- [`SCENE_WINDOW_GRAPH.md`](SCENE_WINDOW_GRAPH.md): the scene window graph (SWG), a conceptual model of everything
  the player sees that is not the 3D world: its terms (render, UIE) and a mental picture, with no SWG file yet.
- [`slides/`](slides/README.md): the official slide deck of the game as it is now, with pictures of the game.
- [`slides_preliminary/`](slides_preliminary/README.md): the preliminary design deck, from before the game was built,
  kept for history.
- [`brainstorm/`](brainstorm/): raw notes that `DESIGN.md` is based on.
